# P12: hardening

The maintainer, 2026-11-16: P12 after P7. The phase as `ACTIVE.md` had it: fuzzing campaigns (every target built first), a sandbox review,
key rotation drills, and a threat model.

## What constrains it

- **ASan.** Every fuzz target is built `-fsanitize=fuzzer,address,undefined`, and ASan cannot start on the build nodes' 4K-page kernels
  (39-bit VMA). The the coordinator session is building a 4K-page kernel with a 48-bit VA (the maintainer's go, 2026-11-16), after
  which ASan and TSan both run. Until then the targets can be built and checked, not run.
- **No builds on the Mac.** libFuzzer is clang's: clang 19 on node-b, node-a and node-c.
- **The store and keyring are frozen** until P8; hardening them means tests and fuzzing, not changes, unless something is found.

## Steps

| ID | Step | State |
|---|---|---|
| H1 | Every fuzz target built with clang 19 (`LUGH_BUILD_FUZZING`), the two written for P10 and P11 (`fuzz_client`, `fuzz_webauthn`) committed with them; a seed corpus per target under `lugh/fuzz/corpus/<target>/`, a handful of valid inputs each | |
| H2 | Campaigns, once ASan runs: each target an hour on 2 cores, `-max_len` suited to it; every crash a regression test in `lugh_tests` and its fix; what ran and for how long recorded | |
| H3 | The sandbox on a real host: `cmake --install` on a build node, then `systemd-analyze security lugh`, and the three never tried on Linux: `LoadCredentialEncrypted=`, `LimitMEMLOCK`, `MADV_DONTDUMP` (a core dump holds no key) | |
| H4 | Key rotation drills on the real binary: a signing key rotated while tokens are being verified, so none signed before is refused while the old key is published; the automatic 90-day rotation on stepped time | |
| H5 | `docs/threat-model.md`: each surface (HTTPS, the sign-in, the API, OAuth, LDAP, the dashboard, the store and keyring, the node's host), what it trusts, what an attacker holding each credential can do, and what stops them | |

H3 needs a build node the maintainer names for an installed service (a systemd unit on a shared machine).
